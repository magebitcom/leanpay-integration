# Functionality

The plugin adds Leanpay installment payments to a Magento shop: a payment method at checkout, a monthly installment badge next to prices, promotions that pick Leanpay's financing programs, and an import that keeps Leanpay's plans current.

| Area | What it covers |
|---|---|
| [Paying with Leanpay](paying-with-leanpay.md) | The checkout, the hand-over to Leanpay, how an order is confirmed or canceled, when the method is offered, markets and environment mode |
| [Installment display](installment-display.md) | The badge and calculator on the home page widgets, listings and product page, and the settings for its look |
| [Promotions](promotions.md) | Financing products on products, categories and whole carts, how conflicts are settled, clearing expired data |
| [Installment plans](installment-plans.md) | The import of Leanpay's plans, its cron job, console command and Refresh button |

The Leanpay API itself is in [integrations](../integrations/README.md); the system map is in [architecture](../architecture/README.md).
